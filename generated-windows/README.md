# حزم النوافذ المولدة

تم توليد عقد موحد لكل نافذة من مصفوفة `docs/window-parity/window-parity-matrix.csv`. هذه الحزم تمنح كل نافذة هيكلاً قابلاً للتحميل في طبقة التشغيل، لكنها لا تدّعي استعادة منطق Oracle غير الموجود في الأدلة.

## الملف

`window-scaffolds.json` يحتوي 1,490 عقدة، ولكل عقدة الشاشة والحقول المرصودة والإجراءات والـTriggers والجداول والحزم والتقارير والصلاحيات وحالات الاستخدام والفجوات.

## الحالة

الحالة `GENERATED_SCAFFOLD` تعني أن الهيكل مولد وقابل للتوسعة. لا تصبح النافذة `VERIFIED` إلا بعد توفير المصدر القديم وإجراء اختبار مقارنة على بيانات متطابقة.
