# Cloud Onex ERP

نظام ERP عربي حديث يعيد بناء نوافذ Oracle Forms/ERP القديمة داخل Workbench موحد، مع ربط العمليات بالمخزون والحسابات والعملاء والموردين والتدقيق. يحافظ المشروع على العقود الوظيفية للنوافذ القديمة، ويقدم واجهات تشغيلية حديثة متوافقة مع دورة المستندات والترحيل الذري.

## الحالة الحالية

المشروع يعمل على فرع `main` ويحتوي على Workbench متعدد النوافذ والتبويبات، مع دعم الواجهات العربية واتجاه RTL، والمزامنة عند العمل دون اتصال، وربط بيانات D1/قاعدة البيانات بحسب بيئة التشغيل.

تم تحديث الوحدات التالية:

- **المبيعات والعملاء:** فاتورة مبيعات متقدمة، دورة أمر البيع والصرف، الدفع الجزئي، العملات المتعددة، فحص المخزون، الترحيل المحاسبي، وحالة الفاتورة الإلكترونية.
- **بيانات الأصناف:** إضافة وتعديل وحذف أو إيقاف الأصناف، البحث والفلترة، تكلفة الوحدة، حالة الصنف المخزني، وربط حسابات الإيراد والمخزون وتكلفة المبيعات.
- **الدليل المحاسبي:** شجرة الحسابات، الحساب الأب، المستويات، طبيعة الحساب، حالات الحساب، الحسابات المرتبطة بالمبيعات والمشتريات والمخزون، والاستيراد من CSV.
- **إدارة المخازن:** مركز مستندات المخزون، الاستلام، التحويل، الجرد والتسوية، حركة المخزون، لوحة صحة المخزون، سياسات إعادة الطلب، مواقع التخزين، وتتبع الدفعات والأرقام التسلسلية.
- **العقود والنوافذ:** جميع النوافذ المعرفة في Workbench مرتبطة بعقود تشغيل تحتوي على الحقول والإجراءات والجداول والملاحظات الوظيفية اللازمة.

## التشغيل المحلي

بعد استنساخ المشروع وتثبيت Node.js وpnpm:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

للفحص والبناء:

```bash
pnpm check
pnpm build
```

- `client/src/pages/WindowWorkbench.tsx`: Workbench الرئيسي والتبويبات والوحدات.

- `client/src/components/ItemMasterPanel.tsx`: شاشة بيانات الأصناف.
- `client/src/components/AccountCatalogPanel.tsx`: شاشة الدليل المحاسبي وشجرة الحسابات.
- `client/src/components/AdvancedWarehousePanel.tsx`: شاشات إدارة المخازن المتقدمة.
- `client/src/components/InventoryDocumentCenter.tsx`: الاستلام والتحويل والجرد.
- `client/src/components/ItemTracePanel.tsx`: حركة المخزون وتفاصيل التتبع.
- `client/src/window-runtime/legacyContracts.ts`: عقود النوافذ وحقولها وإجراءاتها ومصادرها.
- `server/routers.ts`: عقود tRPC ومسارات الواجهة الخلفية.
- `server/db.ts`: خدمات البيانات والترحيل والتكامل المحاسبي والمخزني.
- `drizzle/`: مخططات وترحيلات قاعدة البيانات.
- `docs/`: وثائق التكامل ودورات المشتريات والمبيعات والمخزون والحسابات.

## النوافذ والعقود

توجد العقود في `client/src/window-runtime/legacyContracts.ts`. يحتوي كل عقد على:

- الحقول ونوع كل حقل وما إذا كان مستخرجًا أو مستنتجًا.
- الإجراءات المتاحة مثل الحفظ والاستعلام والطباعة والترحيل والعكس.
- الجداول ومصادر البيانات المرتبطة بالنافذة.
- الإجراءات والإجراءات القديمة المستخرجة من Oracle Forms.
- ملاحظات وظيفية توضح حدود التنفيذ الحالي.

تمت إضافة عقود تشغيل للنوافذ التي كانت موجودة في التبويبات دون تعريف كامل، بما فيها نوافذ المبيعات والمشتريات والمخزون والحسابات والصناديق والبنوك.

## الأرشيفات وإعادة البناء

الأرشيفات الأصلية كبيرة، لذلك تم تقسيمها إلى أجزاء مناسبة لـ GitHub مع ملفات SHA-256. بعد استنساخ المشروع، شغّل:

```bash
./scripts/reassemble_sources.sh
```

سيعيد إنشاء الملفات والأرشيفات داخل `reconstructed/` ثم يتحقق من البصمات المسجلة.

## التوثيق والتحليل

- `docs/`: وثائق دورة الحسابات والمبيعات والمشتريات والمخزون والتكامل.
- `database_analysis/`: فهارس منقحة للجداول والحقول والقيود والروابط مع كتالوجات Forms.
- `phase1_import_extraction/`: سكربتات ودليل استخراج المرحلة الأولى من Oracle Test Schema.
- `rebuild-manifest/`: حالة إعادة بناء النوافذ ومصادرها.
- `generated-windows/`: مخططات النوافذ المولدة.
- `legacy-source/`: عقود النوافذ القديمة وكتالوجات التتبع والتكامل.

## حدود التحليل

ملفات `FMX` و`PLX` المجمعة لا تعطي المصدر الكامل لكل Trigger أو Package. تحفظ الكتالوجات السلاسل والاعتماديات المستخرجة، بينما يلزم الحصول على `FMB` و`PLL/PKS/PKB` وDDL قاعدة البيانات لتحليل المصدر سطرًا بسطر.

## ملاحظة أمنية

لا يحتوي هذا المستودع على ملفات الاتصال الخام أو السجلات غير المنقحة. تم حجب مؤشرات كلمات المرور والأسرار من التقارير والكتالوجات القابلة للتسليم. يجب مراجعة الملفات المصدرية قبل جعل المستودع عامًا.

لا تستخدم سكربتات استخراج Oracle على قاعدة الإنتاج مباشرة. راجع المعلمات والصلاحيات واسم الـSchema قبل التشغيل.

## الترخيص والملكية

هذا المستودع مخصص لتطوير Cloud Onex وإعادة بناء وظائف ERP القديمة. راجع سياسة المشروع قبل إعادة التوزيع أو نشر الأرشيفات المصدرية.
