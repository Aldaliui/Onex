# نقل وظائف BetaSys وتجهيز دليل الحسابات

## نطاق هذه المرحلة

هذه المرحلة تنقل الوظائف القابلة لإعادة الاستخدام من BetaSys إلى Cloud Onex دون دمج تاريخ Git أو نسخ ملفات Access الثنائية إلى التطبيق. تم اعتماد Cloud Onex كالمستودع الرئيسي، ونُقلت الوظائف التالية:

1. محول قراءة لقطة `legacy_accounts` و`legacy_items` و`legacy_parties`.
2. حلّ `legacy_accounts.parentId` من خلال `sourceId` إلى `accountNo` بدل تمرير معرف المصدر كرمز حساب.
3. استنتاج نوع الحساب من أول رقم في رمز BetaSys مع إبقاء الحسابات غير المعروفة ضمن `ASSET` للمراجعة.
4. تحديد الحسابات القابلة للترحيل من خلال كونها أوراقًا في الشجرة، وتحويل الحسابات الأب إلى حسابات تجميعية.
5. الحفاظ على الرصيد الافتتاحي في المعاينة فقط؛ لا يتم إنشاء قيود افتتاحية تلقائيًا قبل اعتمادها.
6. ربط الأصناف افتراضيًا بالحسابات `4100` و`1300` و`5100` الموجودة في دليل الحسابات القياسي.
7. إضافة اختبارات تمنع كسر الهرمية أو تمرير رموز مكررة.

## دليل الحسابات القياسي

يوجد الدليل في:

`config/chart-of-accounts/default-ar.json`

يحتوي الإصدار الأول على 27 حسابًا، منها 5 حسابات جذرية و16 حسابًا قابلاً للترحيل. الحسابات الأساسية المستخدمة في عمليات ERP هي:

| الرمز | الحساب | الاستخدام |
|---|---|---|
| 1300 | المخزون | أصل مخزني |
| 1410 | حسابات العملاء | حساب تحكم للذمم المدينة |
| 2110 | حسابات الموردين | حساب تحكم للذمم الدائنة |
| 2190 | بضاعة مستلمة غير مفوترة | الاستلام قبل الفاتورة |
| 2200 | ضرائب مستحقة | الضرائب الدائنة |
| 4100 | إيرادات المبيعات | إيرادات البيع |
| 5100 | تكلفة البضاعة المباعة | تكلفة المبيعات |
| 5300 | خسائر فروقات الجرد | تسويات النقص |

## التشغيل

إنشاء معاينة من لقطة BetaSys:

```bash
BETASYS_SNAPSHOT=/path/to/database_snapshot.sql \\
BETASYS_IMPORT_OUTPUT=artifacts/betasys-import-preview.json \\
node scripts/import-betasys-data.mjs
```

التطبيق الفعلي لا يُنفذ إلا بعد إعداد `CLOUDFLARE_WORKER_URL` و`ONEX_API_TOKEN` ومراجعة المعاينة:

```bash
CLOUDFLARE_WORKER_URL=https://... \\
ONEX_API_TOKEN=... \\
BETASYS_SNAPSHOT=/path/to/database_snapshot.sql \\
node scripts/import-betasys-data.mjs --apply
```

لا يتم ترحيل الأرصدة الافتتاحية أو كميات المخزون تلقائيًا في هذه المرحلة؛ يجب إعداد دفعة افتتاحية معتمدة ومطابقتها مع ميزان المراجعة قبل نشرها.
